Требовалась дословная цитата двух спорных мест, чтобы подтвердить/опровергнуть
форму `getattr(self, 'load_general_settings', lambda: {})()`. Полный разбор и
инвентарь всех 7 мест — audits/batch7s21_open_item_quotes.txt. Цитаты дословно:
(1) Supervertaler.py:1803–1815 (место, которое отчёт Stage 1 называл «1809»):
        parent = self.parent()
        while parent:
            if hasattr(parent, 'termbase_highlight_style'):
                highlight_style = getattr(parent, 'termbase_highlight_style', 'semibold')
                ...
                break
            elif hasattr(parent, 'load_general_settings'):
                settings = parent.load_general_settings()
    → `hasattr`-guard по цепочке parent() + ОБЫЧНОЕ обращение к атрибуту;
      формы `getattr(self, …, lambda: {})()` нет.
(2) modules/quicktrans.py:300–305:
        def _load_mt_quick_settings(self) -> Dict[str, Any]:
            """Load MT Quick Lookup specific settings"""
            if hasattr(self.parent_app, 'load_general_settings'):
                settings = self.parent_app.load_general_settings()
                return settings.get('mt_quick_lookup', {})
            return {}
    → `hasattr`-guard на self.parent_app + обычный вызов; lambda-формы нет.
ВЕРДИКТ: формы `getattr(self, 'load_general_settings', lambda: {})()` НЕТ НИ В ОДНОМ
из 7 мест. Полный инвентарь (дерево после S2.1): 1810–1811 (parent()-цепочка),

main window из Superlookup-контекста), modules/quicktrans.py:302–303 (parent_app).
Все — hasattr-guard + обычное обращение к атрибуту на `self` либо на другом объекте.
