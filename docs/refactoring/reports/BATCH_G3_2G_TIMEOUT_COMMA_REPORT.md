разделитель; нормализация в `parse_profile_request_fields` (strip, одна запятая →
точка), затем текущая логика; строки с несколькими разделителями («1,5,5»,
«1.5,5») — невалидны (блок сохранения как сейчас); `max_tokens` / `extra_body`
