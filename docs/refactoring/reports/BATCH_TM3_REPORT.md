### 0a — высота строк (R1a/R1b) — CONFIRMED

Причина: `resizeRowsToContents()` вызывается только в `refresh_browser()`, который
в конструкторе выполняется при **скрытом** виджете — колонки ещё не получили
финальную ширину (Stretch-колонки = 99 px против ~251–302 px после показа).
При показе подвкладки и при resize окна пересчёта нет.

| Замер | «до» | Эталон (QTextDocument по финальной ширине) |
|---|---|---|
| R1a: высоты строк при первом показе | row0: hidden 577 px → shown **577 px** (заморожены), row1: 385 → 385 px | colWidth(Source) 99 → 251 px; эталон по новой ширине — другой класс значений |
| R1b: после расширения окна (colWidth→601 px) | row0 остался **577 px** | нужен **238 px** |

(Цифры сняты на безшрифтовой offscreen-платформе: эталонные абсолютные значения
там зависят от fallback-шрифта; инвариант «высоты заморожены при изменившихся
ширинах» от шрифта не зависит. На ПОСЛЕ-коде: hidden 1351 → shown 343 px —
пересчёт на показе работает, §4.1.)

Примечание метода (в отчёте TM2 этого нюанса не было): у дефолтного делегата Qt6
есть эвристика переноса (QCommonStyle `viewItemSize`), из-за которой
`resizeRowsToContents()` на скрытой таблице считает высоты по своей оценке, а не
по реальной ширине колонки — одна из причин, почему до батча «Refresh» лечил
высоты только частично и почему в задаче 3/1 выбран собственный sizeHint.

### 0b — галка «Whole words» без ✓ (R2a/R2b) — CONFIRMED

Причина: `modules/theme_manager.py:479-486` — тема задаёт
`QCheckBox::indicator, QRadioButton::indicator { border …; background-color: {base} }`
и `:checked { background-color: {highlight} }` **без изображения отметки**. Как
только stylesheet описывает `::indicator`, Qt рисует индикатор по CSS и родную
галку не рисует вовсе.

## 7. Ручная проверка для Дмитрия (D:\Supervertaler_clean после пересборки)

Общие предусловия: проект с несколькими TM, в TM-базе есть длинные записи
(>300 символов) и записи с кириллицей. Для каждой задачи — цель, шаги,
критерий успеха и что считается провалом.

**T-TM3.1 (задача 1, высота строк).** Цель: строки по тексту при первом открытии
и после изменения размера окна, без Refresh. Шаги: открыть TMs → Browse All;
не нажимая Refresh, посмотреть высоту строк; растянуть окно шире/уже; подождать
~0.3 с. Успех: у каждой строки внизу нет пустого поля — высота соответствует
числу строк текста в колонке; после изменения размера окна высоты сами
перестраиваются (до 0.3 с задержки — штатно, дебаунс). Провал: строки заметно
выше текста, «лишние» пустые поля, лечатся только Refresh.

**T-TM3.2 (задача 2, tooltip).** Цель: подсказки на Source/Target убраны.
Шаги: навести курсор на ячейку Source/Target с длинным текстом. Успех: подсказка
не появляется. Провал: всплывает дублирующий текст.

**T-TM3.3 (задача 3, подсветка).** Цель: найденное подсвечивается тем, что
ПРИМЕНЕНО. Шаги: набрать в Filter «пехот» (кириллица) — НЕ нажимая Enter; нажать
Enter; затем включить «Whole words», применить; переключить «Search in: Source
only» и применить; нажать Clear. Успех: после Enter/Filter в ячейках,
попадающих под режим, совпадения подсвечены жёлтым (регистр не важен,
«Пехотная» тоже); в «Source only» колонка Target без подсветки; Whole words
подсвечивает только целые слова; в выделенной строке подсветка остаётся
различимой; после Clear подсветки нет. Провал: подсветка реагирует на набираемый
текст ДО Enter, вылезает вне режима, искажает текст, не видна в выделенной строке.

**T-TM3.4 (задача 4, галка).** Цель: у включённой «Whole words» видна ✓.
Шаги: включить/выключить галку, в светлой и тёмной теме (Settings → тема).
Успех: включённая = зелёный квадрат с белой галкой; выключенная — пустой квадрат.
Провал: включённая — просто цветная заливка без галки.

**T-TM3.5 (задача 5, Clear).** Цель: Clear сбрасывает всё фильтровое.
Шаги: задать текст фильтра + включить Whole words + «Search in: Target only» +
выбрать конкретную TM в списке «TM:»; применить; нажать Clear. Успех: поле
пусто, галка снята, «Search in» = Source and Target, таблица перезагружена;
выбранная TM в списке «TM:» СОХРАНИЛАСЬ (это область, а не фильтр). Провал:
Clear сбросил «TM:» или не сбросил какой-то из фильтров.

**T-TM3.6 (задача 6, редактор — ОСТАНОВЛЕНО, проверять НЕ нужно).** Правка в
таблице осталась как была: двойной клик открывает однострочный редактор,
изменённый текст НЕ сохраняется в БД и откатывается при Refresh. По промпту
задача остановлена (запись в БД из таблицы не существовала и не существует).
Решение о судьбе редактирования — отдельным батчем.

**T-TM3.7 (задача 7, текущая ячейка и Ctrl+C).** Цель: видно, какая ячейка
текущая; Ctrl+C копирует её полный текст. Шаги: кликнуть по ячейке Source
длинной записи в выделенной строке; Ctrl+C; вставить в блокнот; то же с Target
и, для контроля, с колонкой TM; повторить на ячейке с подсветкой. Успех: текущая
ячейка чуть темнее остальных в выделенной строке; в буфере — полный текст именно
той ячейки, без разметки/подсветки. Провал: буфер пуст, копирует другую ячейку,
обрезает текст или тянет разметку.

**T-TM3.8 (задача 8, свежесть).** Цель: Browse All всегда показывает БД.
Шаги: (а) открыть TMs → TM List, удалить TM (Delete TM → Yes); (б) пока открыта
подвкладка Browse All — она должна перезагрузиться сама; (в) снова удалить/создать
TM, находясь на подвкладке TM List (Browse All скрыта), затем перейти на Browse All.
Успех: (а) записи удалённой TM исчезли сразу, без Refresh; (в) после перехода
данные актуальны, выбранные фильтр/сортировка сохранены, выделение сброшено;
удалённая TM в списке «TM:» сменилась на «All TMs». Провал: записи удалённой TM
видны до нажатия Refresh (исходный баг ручного теста TM2).

**T-TM3.9 (задача 9, список «TM:»).** Цель: просмотр одной TM без подвкладок.
Шаги: в Browse All выбрать TM в списке «TM:» (без Enter); проверить состав;
поставить Show: 100 при TM с >100 записями; выбрать «All TMs». Успех: таблица
перезагружается сразу после выбора; показаны ровно записи этой TM (колонка TM
одна и та же); при Show:100 — ровно 100 записей (лимит действует после
TM-ограничения); «All TMs» возвращает всё; строка «Showing N entries» как раньше.
Провал: после выбора нужны Enter/Refresh, видны чужие записи, лимит режет до
TM-ограничения.
