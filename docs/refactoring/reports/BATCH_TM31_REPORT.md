# BATCH TM3.1 — Browse All: исправление регрессий TM3 (отрисовка, контраст, применение фильтра, проводка свежести)

Дата: 2026-11-20. База: HEAD `9ebb8f88` (BATCH TM3 (3/3), локально, не запушен).
Исполнитель: агент. Координатор: Dmitry (промпт BATCH TM3.1 от 2026-11-20).

Ручной тест BATCH TM3 (скрины Дмитрия) выявил 4 дефекта (S1–S4), которые
offscreen-тесты TM3 не ловили: они проверяли расчёт высот и прямые вызовы
хуков, а не фактическую отрисовку и не реальные пути проводки. BATCh TM3.1
чинит их поверх TM3 (без откатов).

## 1. Разведка (задача 0) — `docs/refactoring/audits/tm31_recon_before.py`

Скрипт запускается в двух режимах: R1–R3 — в главном процессе **на платформе
«windows» с реальными шрифтами** (окно за пределами экрана, отрисовка
снимается `grab()`), R4 — полный запуск `SupervertalerQt` в подпроцессе
(изолированный профиль). Найдено при разведке и учтено в реализации:

* **Палитра под QSS ≠ нарисованный фон.** `palette.highlight()` = `#0078d7`
  (нативный Windows), а реально рисуется `#e3f2fd` (правило
  `QTableWidget::item:selected` из `theme_manager.py:411`). Следствие:
  цвет текста/фона нельзя брать из палитры — фон измеряется рендером стиля
  в тайл (см. задачу 2).
* **offscreen-платформа без шрифтов флакует access violation'ом** при
  построении полного приложения («Cannot find font directory…»): 4 падения из
  5 попыток, faulthandler показал главную нить без Python-кадров. Прогон R4
  переведён на платформу «windows» — стабильно 6/6. (В реальном приложении
  дефект не воспроизводится — у него каталог шрифтов есть.)
* **Подвкладка, репарентинг и явный hidden-флаг**: не-текущая страница
  QTabWidget уносит явный hidden-флаг с собой при переносе в другой контейнер
  (mini-probe `show_event_probe.py`); в реальном приложении переключение
  страницы делает `setVisible(True)` явно, поэтому show-путь работает.

### 0a (S1) — два пути отрисовки делегата (R1a/R1b)

`_BrowserCellDelegate.paint()` TM3 имел **две ветки**: с подсветкой —
QTextDocument (перенос), без подсветки — `painter.drawText(..., AlignLeft |
AlignVCenter)` **без TextWordWrap** (одна строка, обрезка), при этом
`sizeHint()` всегда считал высоту многострочного документа.

Замер по пикселям (реальные шрифты, текст ~6 строк переноса):

| Замер | Значение |
|---|---|
| Ожидается строк переноса (QTextLayout, ширина ячейки − PAD_X) | **12** |
| Реально отрисовано без фильтра | **1** (чернила 9 px, одиночная строка 12 px) |
| Межстрочный шаг | 17 px |
| Высота строки (от sizeHint) | **199 px** — «пустое поле под текстом» |
| Реально отрисовано с фильтром | **12** (чернила 198 px) |

[CONFIRMED] R1a: без фильтра рисуется 1 строка при 12 расчётных.
[CONFIRMED] R1b: с фильтром тот же текст рисуется по-другому (второй путь).

### 0c (S3) — «Search in»/«Whole words» не применяются (R3)

Статика: `browser_search_in.currentIndexChanged` и `browser_whole_words.toggled`
**не подключены** ни к чему (grep модуля). Динамика (фильтр «пехот» активен,
5 строк): смена «Source only» → строк **5** (ожидалась 1), подсветка Target
всё ещё включена; включение Whole words → строк **5** (ожидалось 0).
«Применённый» фильтр — просто текст поля, перечитываемый только в
`refresh_browser` (Enter/кнопка Filter/TM-выбор).

[CONFIRMED] R3a, [CONFIRMED] R3b.

### 0d (S4) — проводка свежести (R4, исполнение на реальных кнопках)

Статическая цепочка (Supervertaler.py):

* `create_translation_memories_tab` (10862): обёртка TM3 на 10905 читает
  `getattr(self, 'tm_tab_refresh_callback')` **после** того, как
  `_create_tm_list_tab` (10890) уже присвоила атрибут (11268) — обёртка
  **устанавливается** (`callback_name = _refresh_tm_list_and_browse`,
  подтверждено исполнением). Но:
* **кнопки create/import/delete получают замыкание `refresh_tm_list` как
  ПАРАМЕТР** (11278, 11286, 11301) и вызывают его **в обход атрибута** —
  обёртка на этих путях мертва (гипотеза Дмитрия подтверждена, в варианте
  «захвачено замыкание-параметр»);
* TMEditorDialog (18787) и Match Panel (34021) вызывают атрибут — эти пути
  работали;
* `self.refresh_tm_list()` (39811, 52479) — метод-заглушка no-op (52868), к
  проводке не относится;
* список «TM:» строится в `_reload_browser_tm_combo`, который вызывался
  только из `load_initial_data` (создание диалога), `on_import_finished`,
  `on_tm_list_changed` (видимая вкладка) и `_on_browser_shown` (только при
  dirty-флаге) — ни при каждом refresh_browser, ни на каждом показе.

Исполнение (реальные кнопки «+ Create New TM» / «🗑️ Delete TM», диалог
создания заполняется через обезвреженный `QDialog.exec`, `QMessageBox.question`
→ Yes; Browse All скрыт, как у пользователя):

| Фаза | ДО (TM3) | ПОСЛЕ (TM3.1) |
|---|---|---|
| 2: создание TM B кнопкой | `combo=[None]` — B нет; `changed=1→1` | `changed` +1 |
| 3: показ Browse All | `combo=[None]` — B **не появилась даже после показа** (dirty=False) | combo содержит B |
| 4: удаление TM A кнопкой | `changed` не изменился — путь не уведомляет | `changed` +1 |
| 5: повторный показ | **строки 3/3 — записи удалённой TM висят** | **combo=[None, B], rows=0** |

Итог разведки: [CONFIRMED] R4a (созданная TM не появляется в «TM:» даже после
показа), [CONFIRMED] R4b (записи удалённой TM висят в Browse All). Счётчик
реальных вызовов `on_tm_list_changed`: ДО — 1 (только setup), ПОСЛЕ — 3
(setup + обе кнопки). На ПОСЛЕ-коде R4a/R4b — [NOT-REPRODUCED].

## 8. Ручная проверка для Дмитрия (T-TM3.1.1–5)

Сборка: `D:\Supervertaler_clean` (без пересборки — код попадает туда при
следующем обновлении билда по решению Дмитрия). Профиль пользователя не
затрагивается: все проверки в приложении.

**T-TM3.1.1 (S1, перенос без фильтра) — обязательный.**
1. Открыть Workbench → вкладка «💾 TMs» → подвкладка «📖 Browse All».
2. Не вводя фильтр, посмотреть длинные записи в колонках Source/Target.
Ожидается: текст переносится по словам по ширине колонки, виден ВЕСЬ текст
(как после Refresh в TM2), без обрезки и многоточий; «пустых полей под
текстом» нет — высота строки ровно под текст. Проверить при изменении
ширины окна (потянуть край) — текст переразбивается на строки без Refresh.
Провал: одна обрезанная строка при высокой строке.

**T-TM3.1.2 (S2, контраст) — обязательный.**
1. Кликнуть по строке, походить по ячейкам Source/Target.
2. Повторить в светлой теме (по умолчанию) и в тёмной (Settings → тема).
Ожидается: текст читаем всегда — белый на тёмном фоне выделения/текущей
ячейки, тёмный на светлом; подсвеченные фрагменты — тёмный текст на жёлтом.
Провал: белый текст на бледно-голубом, тёмный на тёмно-синем, нечитаемое
что-либо.

**T-TM3.1.3 (S3, мгновенное применение) — обязательный.**
1. В поле Filter ввести фрагмент, который есть в Target (например, слово из
перевода), нажать Filter.
2. Не трогая поле, сменить «Search in» на «Source only» — список и подсветка
должны обновиться СРАЗУ (без Enter/Filter).
3. Включить «Whole words» — тоже сразу; выключить — сразу.
4. Очистить поле (Clear) — вернуть «Source and Target».
Ожидается: каждое изменение сразу меняет список строк и подсветку; подсветка
в колонках только выбранного режима; поиск по «Пехотная»/«ПЕХОТНАЯ» находит
запрос «пехот» и подсвечивает. Провал: список/подсветка меняются только после
Enter/Filter.

**T-TM3.1.4 (S4, проводка свежести) — обязательный.**
1. Создать новую TM («+ Create New TM», любая пара языков, добавить через
импорт TMX или просто запомнить имя).
2. Переключиться на «📖 Browse All» — новая TM должна быть в списке «TM:»
(выбор «All TMs» показывает её записи, если они есть).
3. На «📋 TM List» выделить какую-нибудь TM с записями → «🗑️ Delete TM» →
подтвердить.
4. Переключиться на «📖 Browse All».
Ожидается: удалённой TM нет в «TM:» (если была выбрана — откат на «All TMs»),
её записей нет в таблице — БЕЗ нажатия Refresh. По логу программы (консоль):
`TM Browser: TM list changed, reloading` (при открытой вкладке) или
`TM Browser: TM list changed (reload deferred to show)` + 
`TM Browser: reloaded on show (N entries)`. Провал: записи/TM остаются до
Refresh.

**T-TM3.1.5 (задача 5, read-only) — обязательный.**
1. Двойной клик по любой ячейке Browse All.
Ожидается: редактор НЕ открывается, ничего не меняется. Delete по выделенной

редактор / введённый текст куда-то «пропал».

*Опционально:* Ctrl+C на ячейке Source/Target копирует полный текст без
разметки (проверка TM3 сохранена — сьют T-S5-… / tm3 T25–T28).
