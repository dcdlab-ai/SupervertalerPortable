# ОТЧЁТ BATCH I2.1 — обратная связь в окне экспорта Tagged Text (статусная строка Save/Load)

Дата: 2026-11-08. Исполнитель: агент (ZCode). Координатор: Дмитрий.
Правка ТОЛЬКО в `modules/tagged_text_export_dialog.py` (+ тесты, docs);
`Supervertaler.py` и остальное не тронуты (sha256 до = после в обеих формах).
Пуша нет.

## s0. Итог

Проблема T-I2c (Дмитрий): кнопка Save серии не давала никакой реакции —
непонятно, сохранилось ли. Сделано: **немодальная статусная строка** (QLabel
под блоком «серия») в окне экспорта:

- после Save — «Saved: <полный путь к .tagmap.json>» (зелёным);
- после Load — «Loaded: <имя серии>» (зелёным);
- ошибки — тем же полем **красным**, **без модальных окон**: пустое имя серии
  при Save («Enter a mapping set name first.») и при Load («Enter a mapping
  set name.»), недопустимые символы имени (`\ / : * ? " < > |`, ведущая
  точка), отсутствие файла серии, сбой записи/чтения, битый JSON;
- строка **сбрасывается при смене имени серии** (`textChanged`);
- строки UI — `self.tr(...)`, как у соседей; интерполированные тела —
  `%s`-подстановка после `tr` (перевод соберётся на регенерации XLF в конце
  I-серии, решение Q2).

Попутно (в пределах того же файла и той же переработки обработки ошибок,
предписанной промптом) исправлен **латентный баг I2**: `_load_series` при
пустом имени серии обращался к неопределённой переменной `path` до её
присваивания (NameError вместо сообщения) — ветка существовала со времён I2
и не покрывалась тестами; теперь покрыта (тест A23).

Модальное окно при валидации имён стилей перед «Export» не менялось (другой
поток — проверка таблицы соответствий, не серий).
