## s1. Что сделано

### 1. `modules/prompt_markers.py` — НОВЫЙ (56 строк)

* Константы `SURROUNDING_CONTEXT_HEADER` / `SURROUNDING_CONTEXT_EXPLAINER` /
  `TRANSLATE_THIS_MARK` — строки байт-в-байт те же, что прежние литералы
  (тест A1; тест C2 дополнительно сверяет собранный промт целиком, §s2).
* `looks_like_prompt_echo(response, source_text) -> bool` — сигналы (срабатывает любой,
  КОГДА маркера нет в `source_text`):
  * (а) парные `>>>` и `<<<`;
  * (б) регэксп `>>>\s*\d+\s*\.`;
  * (в) литерал `SURROUNDING SEGMENTS FOR CONTEXT`.
* Голые «27.»/«28.» без `>>>` НЕ ловятся (контракт, тесты A9/A11); вырезание перевода из
  мусора не выполняется. Модуль без зависимостей (только `re`) — без цикла импорта.

### 2. `modules/llm_clients.py` (+28)

* `LLMPromptEchoError(LLMResponseError)` — типизированная, как `LLMTruncatedError` (G3.2):
  наследник `ValueError`, так что существующие `except ValueError` продолжают работать
  (тест B5).
* `translate()` и `translate_with_usage()`: новый параметр `detect_prompt_echo: bool = False`,
  передаётся по цепочке. При `True` **после** `_clean_translation_response` — проверка
  `looks_like_prompt_echo(result, text)`; при срабатывании — `LLMPromptEchoError` с превью
  ответа (200 символов). Остальные вызывающие не менялись; чат/QuickTrans/AutoTagger не
  затронуты (тест B2: без флага эхо-ответ проходит).

### 3. `Supervertaler.py` — `translate_current_segment` (+90/−18; зоны — §s6)

* Блок контекста :48525–48559 собирается из констант `modules/prompt_markers` — текст промта
  **байт-в-байт прежний** (тесты A1 + C2: промт первого вызова равен эталонной сборке
  прежними литералами, посимвольно).
* `surrounding_context = ""` поднят из `try` на уровень метода (нужен обработчику эха).
* Вызов `client.translate(..., detect_prompt_echo=True)` (единственное место с флагом — Q1).
* При `LLMPromptEchoError`: **один повтор** с промтом, из которого убрано ровно то, что было
  вставлено (контекст + разделяющие пустые строки; аккуратный undo вставки через
  `replace(..., 1)` / `endswith`). При успехе повторного вызова — строка в лог
  `↻ Retry without surrounding context: segment #%s translated` (тесты C3–C6).
* При повторном эхо: `translation=None`, `echo_skipped=True` → выход **до** записи в target,
  пополнения TM, undo и смены статуса (Q3); лог
  `⚠ Prompt echo in the model response — segment #%s left untranslated (%s/%s)`; без
  модальных окон (ветка `QMessageBox "Translation Failed"` не достигается — тесты C7–C11).
* Новые строки пользователя — `self.tr` с `%s`-подстановкой (XLF — по решению Q2 серии I,
  одним шагом в конце).

### 4. `modules/tagged_text/writer.py` (+18/−1) + монолит, export_tagged_txt

* `write_tagged_text(..., source_lines=None)`: когда передан список исходников (1:1 с
  физическими строками `md_text`), каждая строка-перевод проверяется детектором; попадание →
  `report.warnings.append('похоже на эхо промта (строка N): <превью 80>')` — тот же формат
  `_line_suffix`, что у предупреждений о картинках. **Только предупреждение, экспорт не
  блокируется.** Без `source_lines` проверка не выполняется — CLI/регресс не меняются
  (тест C14).
* В `export_tagged_txt`: `_collect_source_lines(segments)` (новый хелпер, зеркальная
  группировка по `paragraph_id` + `join_segments`) и разворачивание логических строк до
  физических (target с переводами строк даёт несколько строк md; нумерация предупреждений
  совпадает со строками документа). Окно отчёта уже показывает warnings — UI не менялся.

## s8. Ручная проверка (Дмитрий; по желанию, обе опциональны)

* **T-C1. Защита при переводе.** Открыть проект, выбрать непереведённый сегмент, нажать
  Ctrl+T с профилем nailong-9b и включённым «окружающие сегменты» (по умолчанию 5).
  Если модель вернула каркас — в панели лога появится «⚠ Prompt echo detected — retrying
  without surrounding context (segment #N)», затем либо «↻ Retry without surrounding
  context…» и перевод в ячейке, либо «⚠ Prompt echo … left untranslated (provider/model)»,
  ячейка останется пустой, статус сегмента не изменится. Неуспех: модальное окно
  «Translation Failed» или мусор в ячейке.
* **T-C2. Предупреждение при экспорте.** В любом проекте вписать в target какого-нибудь
  сегмента строку с «>>> текст <<<» (у которой в исходнике таких маркеров нет), выполнить
  Project → Export → InDesign Tagged Text (TXT) и экспортировать. В окне отчёта экспорта
  среди предупреждений должна быть строка «похоже на эхо промта (строка N): …». Неуспех:
  предупреждения нет или экспорт прервался.
