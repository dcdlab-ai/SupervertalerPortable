# BATCH C1.1 — Окно отчёта экспорта Tagged Text: предупреждения заметны

**Дата:** 2026-11-09. **Проблема (T-C2, Дмитрий):** предупреждение «похоже на эхо промта
(строка N): …» стоит последним в списке, тем же шрифтом и чёрным цветом, длинная строка
уходит за границу текстового поля, окно приходится растягивать вручную.
**Скоуп:** только `_show_tagged_text_report` (Supervertaler.py:30265→30267). Логика экспорта
и writer **не менялись**. **Пуша нет.**

## s1. Что сделано

Было: `QPlainTextEdit` с цельным `report.to_text()` (минимум 560x420, всё одним шрифтом,
горизонтальная прокрутка на длинных строках).

Стало:

1. **Окно изменяемого размера**: `resize(820, 560)`, `setMinimumSize(720, 420)` (было
   `setMinimumSize(560, 420)`); диалог и раньше был resizable, теперь и стартовый размер
   разумный, и минимум по промпту.
2. **Прокручиваемое поле с переносом**: `QPlainTextEdit` → `QTextEdit` (read-only),
   `setLineWrapMode(WidgetWidth)` — длинные строки переносятся, горизонтальной прокрутки
   нет (проверено тестом: `horizontalScrollBar().maximum() == 0`).
3. **Эхо — отдельным блоком наверху**: заголовок «⚠ Prompt echo in the translation — N»
   и каждое предупреждение — красным (#c00000), жирным; остальные предупреждения (картинки
   и т.д.) — ниже, отдельным блоком «Warnings (N)» обычным шрифтом; сводка отчёта — между
   ними. Разделение по подстроке `'похоже на эхо промта'` (константа писателя, менять её
   не нужно).
4. **Число предупреждений**: в заголовке окна («InDesign Tagged Text Export Report —
   N warning(s)») и в первой строке над полем (рядом с именем файла).
5. **«Копировать» без изменений**: кладёт полный прежний `report.to_text()` (секция
   «Предупреждения:» остаётся в копии — тест C1.1-12 сверяет клипборд с `to_text()`
   байт-в-байт).
6. Новые строки — `self.tr` (`%s`-подстановка; XLF — в конце I-серии по Q2). Новых
   модальных окон нет — окно отчёта, как и раньше, один `QDialog`.

**Эхо+картинки** — порядок блоков «эхо → сводка → остальные» (10), заголовок блока с числом
